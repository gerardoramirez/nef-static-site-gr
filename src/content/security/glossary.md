## ASN.1 (Abstract Syntax Notation One)

A standard notation used to describe data structures for certificates and other PKI components.

## CA/Browser Forum

A consortium of Certificate Authorities and browser vendors that establishes Baseline Requirements for certificate issuance.

## Certificate Revocation List (CRL)

A list of certificates that have been revoked before their scheduled expiration date.

## Certificate Signing Request (CSR)

A message sent to a CA to request a digital certificate, containing the public key and identity information.

## DER (Distinguished Encoding Rules)

Binary format for encoding certificates and keys, commonly used for certificate files.

## Distinguished Name (DN)

A structured name that uniquely identifies an entity in an X.509 certificate, including fields like Common Name (CN), Organization (O), and Country (C).

## OCSP (Online Certificate Status Protocol)

A protocol for obtaining the revocation status of a certificate in real-time, more efficient than CRLs.

## PEM (Privacy Enhanced Mail)

Base64-encoded format for certificates and keys, commonly used in text-based configurations.

## PKCS (Public-Key Cryptography Standards)

A series of standards for public key cryptography, including PKCS#12 (.p12/.pfx files) for storing certificates and private keys.

## Root Store

A collection of trusted root CA certificates embedded in operating systems and browsers.

## SAN (Subject Alternative Name)

An X.509 extension that allows a certificate to specify additional hostnames, IP addresses, or identities.

## TLS Handshake

The process by which a client and server establish a secure connection, including protocol negotiation, authentication, and key exchange.

## WebTrust

An audit framework used to verify that Certificate Authorities follow industry standards and best practices.
