## Tikal

[Tikal](https://github.com/gerardoramirez/tikal) is an open-source framework for the instructions, workflows, and scripts used with AI coding assistants.

It gives agents a thin router and loads only the stack docs that match the current repo — plus optional hooks for instruction reload and session telemetry.

I wrote a longer summary in [Tikal — structural alignment for AI coding agents](/writing/tikal-ai-coding-framework), and there is a short product page at [Products → Tikal](/products/tikal).
